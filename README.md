# UltrasonikAlarmParking
Using ultrasonic and 2 esp8266 with espnow communication.When the sensor approaches the object, esp will turn on the buzer.
## Pin Configuration


| Komponen | Pin Arduino | Deskripsi |
| :--- | :--- | :--- |
| LED | Pin 13 | Output Digital |
| Sensor Potensiometer | A0 | Input Analog |
| Servo Motor | Pin 9 | PWM Output |
| GND | GND | Ground |
| VCC | 5V | Daya 5 Volt |
